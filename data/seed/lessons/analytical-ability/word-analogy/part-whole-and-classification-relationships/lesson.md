# Part–Whole and Classification Relationships

## Introduction

**Part–Whole and Classification Relationships** are a core category of word analogy questions that test your ability to recognize structural and hierarchical connections between concepts. Unlike synonym or antonym analogies that compare meaning equivalence, these questions require you to understand how things are composed, organized, and categorized.

In the Philippine Civil Service Examination, part–whole and classification analogies appear because they directly mirror the organizational thinking required in government work: understanding how departments relate to agencies, how individual tasks relate to broader programs, and how specific items belong to general categories. Civil servants must constantly navigate hierarchies — organizational charts, budget breakdowns, legislative structures — making this reasoning skill both testable and practically relevant.

These relationship types are distinct from synonym/antonym analogies in a critical way: they test **structural reasoning** rather than **semantic equivalence**. You are not asking "do these words mean the same thing?" but rather "how does this thing fit within a larger system?"

### Why Part–Whole and Classification Relationships Matter

- Government organizations are hierarchical — understanding part-whole structures is essential for navigating bureaucracy
- Budget documents break wholes into parts (national budget → department allocations → program line items)
- Policy implementation requires classifying items correctly (which regulation applies to which category of employee?)
- Administrative decisions depend on recognizing whether something belongs to a group or is a component of a system
- These questions efficiently test logical precision — many examinees confuse part-whole with category relationships, revealing weak analytical skills

### Common Mistakes Examinees Make

1. **Confusing part-whole with item-category** — "wheel : car" is part-whole (a wheel is a physical component), but "car : vehicle" is item-category (a car is a type of vehicle)
2. **Reversing the relationship direction** — "page : book" (part-to-whole) is different from "book : page" (whole-to-part)
3. **Selecting associated words instead of structural relationships** — "doctor : hospital" is worker-to-workplace, not part-whole
4. **Ignoring the specificity of the relationship** — choosing a loosely related answer when the question demands precise structural correspondence
5. **Treating membership as classification** — "soldier : army" (member-to-group) is different from "soldier : profession" (item-to-category)
6. **Failing to verify both pairs follow identical logic** — checking only that the answer "makes sense" without confirming the relationship type matches exactly


## Learning Objectives

After this lesson, you should be able to:

- Define part-to-whole relationships and identify them in word pairs
- Define whole-to-part relationships and recognize reversed structural direction
- Identify item-to-category relationships where a specific example belongs to a broader class
- Identify member-to-group relationships where an individual belongs to a collective
- Distinguish between all four relationship subtypes without confusion
- Analyze analogy structures by labeling the exact relationship before evaluating choices
- Apply systematic elimination to solve CSE-style relationship analogy questions efficiently
- Recognize and avoid traps that exploit confusion between part-whole and classification logic

## 4.1 What Is a Relationship Analogy?

A **relationship analogy** is a logical comparison that states: two words share a specific structural relationship, and you must find another pair of words that shares the *same type* of structural relationship.

The standard format is:

**A : B :: C : D**

Read as: "A is to B as C is to D."

The key principle: **the relationship between A and B must be identical in type and direction to the relationship between C and D.**

### How Relationship Analogies Function

Unlike vocabulary-based analogies (synonyms, antonyms), relationship analogies test whether you can identify *how things connect structurally*:

| Analogy Type | What It Tests | Example |
|-------------|---------------|---------|
| Synonym | Meaning equivalence | brave : courageous |
| Antonym | Meaning opposition | hot : cold |
| Part-Whole | Structural composition | wheel : car |
| Classification | Category membership | rose : flower |

### The "A is to B" Structure

Every analogy establishes a relationship in the first pair that must be replicated in the second pair:

- "Wheel is to car" → relationship: component of
- "Page is to book" → relationship: component of
- Therefore: Wheel : Car :: Page : Book ✓

### Why Logical Consistency Matters

The first pair establishes a **relationship template**. The second pair must follow that template exactly — same relationship type, same direction, same level of specificity.

**Example of inconsistency:**
- Wheel : Car :: Doctor : Hospital ✗
- Wheel is a *part of* a car, but a doctor is not a *part of* a hospital — a doctor *works at* a hospital. Different relationship type.

**Example of consistency:**
- Wheel : Car :: Engine : Airplane ✓
- A wheel is a component of a car. An engine is a component of an airplane. Same relationship type and direction.

## 4.2 Part-to-Whole Relationships

A **part-to-whole relationship** exists when the first word names a component, section, or element that physically or conceptually belongs *within* the second word (the larger system).

**Formula:** A is a part/component of B.

### Types of Part-to-Whole Relationships

| Type | Description | Example |
|------|-------------|---------|
| Physical parts | Tangible components of a physical object | wheel : bicycle |
| Structural sections | Divisions within a document or structure | chapter : novel |
| Organizational parts | Units within an institution | department : company |
| Functional components | Elements that serve a specific function within a system | keyboard : computer |
| Geographical parts | Areas within a larger region | province : country |

### How to Identify Part-to-Whole Relationships

Ask yourself: **"Is A physically or structurally contained within B?"**

- "Is a page contained within a book?" → Yes → part-to-whole ✓
- "Is a wheel contained within a bicycle?" → Yes → part-to-whole ✓
- "Is a rose contained within a flower?" → No (a rose IS a flower) → item-to-category, not part-whole

### Easy Examples

| petal | flower | A petal is a part of a flower |

## 4.3 Whole-to-Part Relationships

A **whole-to-part relationship** is the reverse of part-to-whole: the first word names the larger system, and the second word names a component or subdivision within it.

**Formula:** A contains/is composed of B.

### Understanding the Reversal

The direction matters enormously in analogy questions:

| Pair | Relationship | Direction |
|------|-------------|-----------|
| page : book | Part-to-Whole | component → system |
| book : page | Whole-to-Part | system → component |
| wheel : car | Part-to-Whole | component → system |
| car : wheel | Whole-to-Part | system → component |

**Critical Rule:** If the question pair shows whole-to-part (e.g., "tree : branch"), your answer must also show whole-to-part — not part-to-whole. Reversing the direction is one of the most common errors.

| Whole | Part | Explanation |

| house | room | A house contains rooms |
| hand | finger | A hand contains fingers |

| face | eye | A face contains eyes |
| year | month | A year contains months |

### Medium Examples

### Advanced Examples

| Whole | Part | Explanation |

### Determining Relationship Direction

**Step 1:** Read the pair and ask: "Which word is bigger/contains the other?"

**Step 2:** If the first word is the container → Whole-to-Part. If the first word is the component → Part-to-Whole.

**Step 3:** Your answer pair must follow the same direction.

**Example Question:** Tree : Branch :: Building : _____
- Tree contains branches (whole-to-part)
- Building contains _____ (must be a part of a building)
- Answer: Floor ✓ (a building contains floors)
- Wrong: City ✗ (a city contains buildings — reversed direction)

## 4.4 Item-to-Category Relationships

An **item-to-category relationship** exists when the first word is a specific example or instance, and the second word is the broader class or category to which it belongs.

**Formula:** A is a type/kind of B.

### The Key Distinction from Part-Whole

This is where most examinees lose points. The difference is fundamental:

| Pair | Relationship | Test Question |
|------|-------------|---------------|
| petal : flower | Part-to-Whole | Is a petal *part of* a flower? Yes. |
| rose : flower | Item-to-Category | Is a rose *a type of* flower? Yes. |
| wheel : car | Part-to-Whole | Is a wheel *part of* a car? Yes. |
| sedan : car | Item-to-Category | Is a sedan *a type of* car? Yes. |

**The deciding question:** "Is A a *component inside* B?" → Part-Whole. "Is A a *kind/type of* B?" → Item-Category.


### Types of Item-to-Category Relationships

| Type | Description | Example |
|------|-------------|---------|
| Object categories | Physical items classified by type | hammer : tool |
| Animal classifications | Species within broader groups | eagle : bird |
| Profession categories | Specific jobs within career fields | nurse : medical professional |
| Academic classifications | Subjects within disciplines | biology : science |
| Food categories | Specific foods within food groups | apple : fruit |
| Vehicle categories | Specific vehicles within transport types | sedan : car |
| Genre classifications | Specific works within artistic genres | sonnet : poem |

### How to Identify Item-to-Category Relationships

Ask yourself: **"Is A one example/type of B?"**

- "Is a rose one type of flower?" → Yes → item-to-category ✓
- "Is an eagle one type of bird?" → Yes → item-to-category ✓
- "Is a wing one type of airplane?" → No (a wing is part of an airplane) → part-to-whole

## 4.5 Member-to-Group Relationships

A **member-to-group relationship** exists when the first word names an individual who belongs to a collective body, team, or organized group named by the second word.

**Formula:** A is a member/individual within B (a collective).

### The Key Distinction from Item-to-Category

| Pair | Relationship | Why |
|------|-------------|-----|
| soldier : army | Member-to-Group | A soldier is an individual within the collective "army" |
| soldier : profession | Item-to-Category | "Soldier" is a type of profession |
| player : team | Member-to-Group | A player is an individual within a team |
| basketball : sport | Item-to-Category | Basketball is a type of sport |

**The deciding question:** "Is B a *collective body* made up of multiple A's?" → Member-to-Group. "Is B an *abstract class* that A belongs to?" → Item-to-Category.

Key difference: Groups are **composed of their members** (an army is literally made of soldiers). Categories are **abstract labels** (the category "profession" is not made of soldiers — it's a classification system).

### Distinguishing Member-Group from Part-Whole

This is a subtle but important distinction:

| Pair | Relationship | Reasoning |
|------|-------------|-----------|
| soldier : army | Member-to-Group | A soldier is an *individual person* within a collective |
| wheel : car | Part-to-Whole | A wheel is a *physical component* of a machine |
| chapter : book | Part-to-Whole | A chapter is a *structural section* of a text |
| student : class | Member-to-Group | A student is an *individual person* within a collective |

**Rule of thumb:** If A is a *person* (or living being) and B is a *collective noun* for a group of such persons, it's member-to-group. If A is a *thing/section* and B is a *larger thing/system*, it's part-to-whole.

## 4.6 Relationship Analysis Techniques

Solving part-whole and classification analogies requires a systematic approach. Here are the core techniques for determining the exact relationship type.

### Technique 1: The Classification Test

For every pair, run through these four questions in order:

1. "Is A a *physical/structural component inside* B?" → Part-to-Whole
2. "Does A *contain* B as a component?" → Whole-to-Part
3. "Is A *a type/kind of* B?" → Item-to-Category
4. "Is A *an individual member of the collective* B?" → Member-to-Group

The first "yes" answer identifies your relationship type.

### Technique 2: Relationship Labeling

Before looking at answer choices, write a one-word label for the relationship:

| Label | Meaning | Example |
|-------|---------|---------|
| COMPONENT-OF | Part belongs to whole | engine : car |
| CONTAINS | Whole includes part | car : engine |
| TYPE-OF | Item belongs to category | sedan : car |
| MEMBER-OF | Individual belongs to collective | driver : team |

Then only accept answer choices that match your label exactly.

### Technique 3: The Replacement Test

Substitute the relationship into a template sentence:

- Part-to-Whole: "A _____ is found inside a _____."
- Whole-to-Part: "A _____ contains a _____."
- Item-to-Category: "A _____ is a kind of _____."
- Member-to-Group: "A _____ is a member of a _____."

**Example:** Wing : Airplane
- "A wing is found inside an airplane." ✓ → Part-to-Whole
- Test answer: Rudder : Ship
- "A rudder is found inside a ship." ✓ → Same relationship

### Technique 4: Direction Verification

After identifying the relationship type, verify the direction matches:

| Question Pair | Direction | Answer Must Be |
|--------------|-----------|----------------|
| page : book | Part → Whole | Part → Whole |
| book : page | Whole → Part | Whole → Part |
| rose : flower | Item → Category | Item → Category |
| soldier : army | Member → Group | Member → Group |

**Common Trap:** The exam may offer an answer that has the correct relationship type but reversed direction. Always check direction.

### Technique 5: Elimination by Relationship Type

If you identify the question pair as part-to-whole, immediately eliminate any answer choice that shows:
- A synonym or antonym relationship
- An item-to-category relationship
- A cause-effect relationship
- A function relationship (tool : purpose)

This typically eliminates 2-3 wrong answers instantly.

## 4.9 Practical Applications of Classification Thinking

Understanding part-whole and classification relationships is not just an exam skill — it directly applies to civil service work and professional reasoning.

### Workplace Organization

- **Filing systems:** Documents are classified by type (memorandum, resolution, ordinance) and filed within organizational units (division → section → individual files)
- **Job classification:** Positions are categorized by salary grade, service type (career vs. non-career), and functional area
- **Budget classification:** Expenditures are categorized as personal services, MOOE, or capital outlay — each containing specific line items

### Government Administration

- **Organizational hierarchy:** National government → department → bureau → division → section
- **Legislative structure:** Congress → Senate/House → committees → subcommittees
- **Judicial hierarchy:** Supreme Court → Court of Appeals → Regional Trial Courts → Municipal Trial Courts
- **Local government:** Region → province → city/municipality → barangay

### Project Management

- **Work breakdown structure:** Project → phases → tasks → subtasks (whole-to-part)
- **Resource classification:** Resources categorized as human, financial, material, or technological
- **Risk classification:** Risks categorized by probability and impact level

### Why Classification Improves Reasoning

- Forces precise thinking about boundaries (what belongs vs. what doesn't)
- Reveals organizational patterns that simplify complex information
- Enables faster decision-making by narrowing options to the correct category first
- Improves communication by ensuring shared understanding of hierarchies

### Why Relationship Analysis Improves Decision-Making

- Identifying whether something is a *part* of a system vs. a *type* of system leads to different administrative actions
- Recognizing group membership vs. category membership affects how policies are applied
- Understanding structural composition helps in resource allocation and organizational design

## 4.10 Step-by-Step Analogy Solving Strategies

Use this systematic approach for every part-whole and classification analogy question:

### The CLIP Method

| Step | Action | What You Do |
|------|--------|-------------|
| **C** — Classify the relationship | Read Pair 1 | Label it: Part-Whole, Whole-Part, Item-Category, or Member-Group |
| **L** — Lock the direction | Note the order | Is it component→system or system→component? Item→class or member→collective? |
| **I** — Insert each choice | Test options | Apply your classification template to each answer choice |
| **P** — Pick the precise match | Select answer | Choose the option that matches both relationship type AND direction exactly |

### Detailed Solving Process

**Step 1: Read the first pair and classify (3-4 seconds)**

Ask the four diagnostic questions:
- Is A a component inside B? → Part-to-Whole
- Does A contain B? → Whole-to-Part
- Is A a type of B? → Item-to-Category
- Is A a member of collective B? → Member-to-Group

**Step 2: Lock the direction (1-2 seconds)**

Note which word comes first — the part or the whole, the item or the category, the member or the group.

**Step 3: Test each answer choice (5-8 seconds)**

Apply your template sentence to each option:
- If Part-to-Whole: "Is [choice A] a component of [choice B]?"
- If Item-to-Category: "Is [choice A] a type of [choice B]?"

**Step 4: Eliminate and select (2-3 seconds)**

- Eliminate choices with wrong relationship types
- Eliminate choices with reversed direction
- Select the most precise remaining match

### Time Management

- Target: 12-18 seconds per question
- If classification is unclear after 5 seconds, flag and return
- Never spend more than 25 seconds on a single item

### Shortcut: The "Is-A" vs. "Has-A" Test

- **"Has-A"** → Part-Whole (a car HAS an engine)
- **"Is-A"** → Item-Category (a sedan IS A car)
- **"Is-Made-Of"** → Member-Group (an army IS MADE OF soldiers)

This three-second test resolves most classification confusion instantly.

## 4.11 Common Errors in Relationship Analogies

### Error 1: Confusing Part-Whole with Item-Category

This is the single most common mistake on the CSE.

| Pair | Correct Classification | Why Examinees Get Confused |
|------|----------------------|---------------------------|
| petal : flower | Part-to-Whole | A petal is physically inside a flower |
| rose : flower | Item-to-Category | A rose is a *type* of flower |
| engine : car | Part-to-Whole | An engine is a component of a car |
| sedan : car | Item-to-Category | A sedan is a *type* of car |

**How to avoid it:** Ask "Can I remove A from B?" If yes (you can remove a petal from a flower), it's part-whole. If no (you can't "remove" a rose from the category "flower"), it's item-category.

### Error 2: Reversing Relationship Direction

| Question | Wrong Answer | Why It's Wrong |
|----------|-------------|----------------|
| Page : Book :: ? | Library : Book | Reversed — library contains books, but the pattern is part→whole, not whole→part |
| Tree : Branch :: ? | Room : House | Reversed — room is part of house (part→whole), but tree:branch is whole→part |

**How to avoid it:** Always identify which word is "bigger" in the question pair, then match that position in your answer.

### Error 3: Selecting Associated Words

| Question | Trap Answer | Why It's Wrong | Correct Answer |
|----------|-------------|----------------|----------------|
| Wheel : Car :: ? | Driver : Car | Driver is associated with car but is not a part | Engine : Airplane |
| Soldier : Army :: ? | War : Army | War is associated with army but is not a member | Player : Team |

**How to avoid it:** Association ≠ structural relationship. "Doctor" and "hospital" are associated, but a doctor is not a *part* of a hospital.

### Error 4: Confusing Membership with Classification

| Pair | Correct Type | Common Misclassification |
|------|-------------|-------------------------|
| soldier : army | Member-to-Group | Often confused with item-to-category |
| soldier : profession | Item-to-Category | Often confused with member-to-group |
| senator : senate | Member-to-Group | The senate is composed of senators |
| senator : legislator | Item-to-Category | A senator is a type of legislator |

**How to avoid it:** Ask "Is B a collective noun for a group of A's?" If yes → member-group. If B is an abstract classification label → item-category.

### Error 5: Overlooking Hierarchy Levels

| Question | Imprecise Answer | Better Answer |
|----------|-----------------|---------------|
| Eagle : Bird :: ? | Dog : Animal | Dog : Mammal (more precise category match) |
| Chapter : Book :: ? | Word : Language | Paragraph : Essay (same structural level) |

**How to avoid it:** Match the specificity level. If the question uses an immediate category (bird, not animal), your answer should also use an immediate category.

### Error 6: Relying on Word Familiarity

Examinees sometimes choose the most familiar-sounding answer rather than the structurally correct one. The CSE deliberately includes familiar-but-wrong distractors.

## Exam Strategies

- Classify the relationship type BEFORE looking at answer choices — this prevents distractor bias
- Use the "Has-A / Is-A / Made-Of" shortcut for instant classification
- If two choices seem correct, check direction — one likely has the relationship reversed
- Match specificity levels: if the question uses immediate categories, don't pick broad ones
- On the CSE, part-whole and classification questions often use Philippine government vocabulary — review organizational structures beforehand
- When stuck, eliminate choices that show clearly different relationship types (synonyms, antonyms, cause-effect) to narrow your options
- Never spend more than 20 seconds on one item — flag and return if classification is unclear
- Read both words carefully — "army" (collective group) vs. "military" (category/institution) changes the relationship type entirely

## Memory Aids

- **HAS-A = Part-Whole** — "A car HAS an engine" → engine : car is part-to-whole
- **IS-A = Item-Category** — "A rose IS A flower" → rose : flower is item-to-category
- **MADE-OF = Member-Group** — "An army is MADE OF soldiers" → soldier : army is member-to-group
- **CONTAINS = Whole-Part** — "A book CONTAINS chapters" → book : chapter is whole-to-part
- **Can I physically remove it?** If yes → Part-Whole. If no → probably Item-Category
- **Is B a collective noun?** (army, team, choir, jury, fleet) → Member-to-Group
- **Is B an abstract label?** (profession, sport, science, tool) → Item-to-Category
- **CLIP method:** Classify → Lock direction → Insert choices → Pick precise match
- **Direction check:** Which word is "bigger"? The bigger word is always the whole/category/group
- **Philippine government hierarchy:** Barangay → Municipality → Province → Region → Country (each level is part-to-whole going left to right)

## Quick Recap

- **Part-to-Whole:** A is a component/section inside B (wheel : car, chapter : book)
- **Whole-to-Part:** A contains B as a component (tree : branch, book : chapter)
- **Item-to-Category:** A is a type/kind of B (rose : flower, hammer : tool)
- **Member-to-Group:** A is an individual within collective B (soldier : army, player : team)
- Direction matters — part→whole is different from whole→part
- Use "Has-A" (part-whole), "Is-A" (item-category), "Made-Of" (member-group) for instant classification
- Eliminate wrong relationship types before comparing remaining choices
- Match specificity levels between question pair and answer pair
- Philippine government structures are common source material for CSE questions
