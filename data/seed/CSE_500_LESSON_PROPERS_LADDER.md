# CSE 500 Lesson Propers Ladder

This is a working curriculum ladder derived from `CSE_500_LESSON_PROPERS.md`.
It is editorial, not official CSC scoring. Each subtest runs from 1 to 100, with the 10 topic rows mapped to 10 difficulty bands.

Band guide:
- `1-10` = Foundation
- `11-20` = Basic
- `21-30` = Core
- `31-40` = Core+
- `41-50` = Application
- `51-60` = Application+
- `61-70` = Integration
- `71-80` = Integration+
- `81-90` = Advanced
- `91-100` = Mastery

Within each topic row, the subtopics stay in the same order as the source file.
